# Market Search 0.1.4

Поиск продаж внутри EVE-клиента: предмет по type ID или названию, предложения
по NPC-станциям всех регионов, расстояние в прыжках и назначение маршрута.
Первая версия для **Windows Native** через EveJS Launcher. Docker не поддержан.

## Установка

1. Закройте EVE-клиенты и остановите игровой сервер.
2. В Launcher откройте **Mods → Add ZIP**, выберите `MarketSearch-0.1.4.zip`
   и включите Market Search для своей установки.
3. Запустите сервер и клиент через Launcher. Через несколько секунд после
   входа персонажем введите в чате **`/marketfind`** или **`!marketfind`**.
   Вариант с `!` подходит и для персонажей без GM-доступа к slash-командам.
4. Введите `21038` или `Capital Construction Parts Blueprint`, нажмите
   «Найти / обновить». Если найдено несколько товаров, выберите нужный
   двойным щелчком в верхнем списке.
5. Выберите станцию в нижней таблице и нажмите **«Задать маршрут»**.

Можно открыть окно сразу с запросом: `/marketfind 21038` или
`!marketfind Capital Construction Parts Blueprint`.

Кнопка заменяет текущие точки маршрута выбранной станцией. Она не включает
автопилот, не отстыковывает корабль и не начинает полёт. При включённом
автопилоте или сохранённой активной перевозке AutoMining требуется сначала
остановить эту навигацию. После смены системы обновите поиск.

## Что показывается

- Только активные продажи с положительным остатком: seed-ассортимент и
  обычные игровые ордера на NPC-станциях. Ордера покупки и цитадели игроков
  в первую версию не включены.
- Одна строка на станцию: минимальная цена, суммарный остаток **по этой цене**,
  станция, система и регион. Более дорогие ордера в объём не включаются.
- Прыжки — кратчайший путь по обычным гейтам от текущей системы персонажа,
  включая систему, в которой он находится на станции. Ansiblex, jump drives,
  временные wormhole-соединения и настройки избегания клиента не учитываются.
  «Нет пути» отличается от нулевого расстояния; маршрут тогда не задаётся.
- Можно сортировать по расстоянию или цене. Клиент строит маршрут по своим
  настройкам, поэтому безопасный маршрут может быть длиннее показанного.
- До 50 совпавших типов при поиске по имени. Используйте английские названия
  из каталога маркета или точный ID. Список станций не обрезается до сортировки.

Маркет читается только для чтения в отдельном worker thread, чтобы поиск
SQLite не занимал основной поток сервера. Запрос выполняется по нажатию,
без постоянного опроса базы. Цены могут измениться после получения списка;
покупка остаётся в обычном окне маркета клиента.

## Путь к базе

По умолчанию читается `[storage] database_path` из
`externalservices/market-server/config/market-server.local.toml`, относительный
к каталогу `externalservices/market-server`. Если daemon запущен с другим
конфигом или на другой машине, путь нужно указать явно. Удалённый daemon в
этой версии не опрашивается.

Создайте в корне установки файл `config/market-search.config.json`:

```json
{
  "databasePath": "externalservices/market-server/data/generated/market.sqlite"
}
```

Разрешён и абсолютный Windows-путь с `\\`. Мод не создаёт отсутствующую базу
и не требует метки конкретного сидера: используется общая схема market.sqlite.
Конфиг относится к локальной установке и не включён в ZIP.

## Совместимость и AutoMining

Нужны Node.js 24+, Launcher 1.0.61+ с loader-модами и поддерживаемый копированный
клиент build 3396210. Формат пакета и клиентские UI-интерфейсы изучены по
[Automining](https://github.com/V0nCleef/EveJS-Automining/tree/1154037ae062f5d0d2f432e0295f60514c4b2b85).

Версии `0.12.6`, `0.12.7.1`, `0.12.8`, `0.12.9`, `0.12.19` в manifest —
фильтр доступности для Launcher, **не обещание проверки каждой сборки**.
Helper дополнительно принимает только три изученных хеша `handshake.js`
(с нормализацией LF/CRLF). Они перечислены в `lib/delivery.js`. Другой исходник
даст `Unreviewed handshake.js (...)`; пришлите эту ошибку для отдельной сверки.
Не отключайте проверку. 2026-09-28 пользователь подтвердил работу выданного
пакета на Discord-сборке 0.12.19 вместе с установленным AutoMining. Сам агент
Windows Launcher и клиент не запускал. Для других сборок работа AutoMining
сама по себе не гарантирует принятие этого мода: у него есть другой fallback.

Market Search не меняет `code.ccp`, файлы EVE-клиента или исходники сервера.
Он дополняет готовый login payload после встроенных/Automining обработчиков,
сохраняя их результат, и регистрирует отдельные RPC/notification/команды.
Два мода используют разные имена и сохраняют предыдущие Module._load hooks.
Отключение: выключить Market Search в Launcher и перезапустить сервер и
все клиенты. Обновление требует такого же перезапуска.

## Диагностика и проверка

Ожидаемые строки сервера: `[MarketSearch] 0.1.3 loaded`, затем
`Attached packet`, `Attached rpc`, `Attached chat` и `Attached plain` по мере
загрузки соответствующих компонентов. `Inactive:` означает отказ загрузки;
`UI delivery skipped:` — несовместимый либо слишком большой login payload.
Если команда сообщает, что UI не готов, проверьте эти сообщения и перезапустите
клиент через Launcher. В клиентском логе companion использует префикс
`MARKET_SEARCH:`; успешное подключение — `READY:0.1.1`.

Проверки на временных данных: ID/название/неизвестный товар, лучшая цена и
объём по ней, фильтрация структур, worker/RPC, BFS/нет пути, read-only SHA-256,
составление login expression вместе с реальным AutoMining в обоих порядках,
launcher helper, синтаксис JS и разбор Python через Python 3. Логика выбора
строк/маршрута проверена с временными адаптерами UI; интерпретатор Python 2
и его отдельный parser здесь отсутствуют.
Статическое ревью не выявило блокирующих дефектов. После передачи ZIP
пользователь подтвердил работу мода в своей Windows-установке («все отработало»).
Отдельный протокол каждого пограничного сценария не предоставлялся.

## Большой пакет входа и совместная работа модов

Исправлена ошибка `UI delivery skipped: Combined login payload is too large`.
Если составное выражение превышает 256 KiB, сжимается всё выражение целиком,
с сохранением прежнего результата и порядка исполнения. Лимит передаваемого
выражения остаётся 256 KiB; исходный текст ограничен 2 MiB. Если сжатие не
помогает, лог сообщает исходный и итоговый размер, вход в игру сохраняется.

Для совместного использования обновить **оба** пакета: Skyhook PI 0.1.4 и
Market Search 0.1.1. Иначе старый Market Search может пропустить своё окно
до выполнения исправленного обработчика Skyhook PI. После обновления
перезапустить сервер и полностью закрыть/запустить клиент. Успешное сжатие
отмечается `UI delivery packed: source=... bytes, wire=... bytes`.

Локально проверены оба порядка доставки, сохранение результата и побочных
эффектов Python-выражения, ограничения размера и композиция с исходниками
AutoMining 1.2.14 (`48f00a6`). Полная Windows/Python 2.7 приёмка не выполнена.

## Открытие из неокома

Требуется Launcher 1.0.69+ с client-menu API v1. После обновления ZIP и
перезапуска сервера/клиента откройте **Neocom → Mods → Market Search**
(русское название пункта: **Поиск на рынке**). Пункт также доступен в общем меню
**Insider → MODS**, если оно предоставляется Launcher.

Адаптер `client/menu.py` регистрирует только пункт и вызывает существующее
окно. Пункт доступен после готовности companion текущего персонажа;
до этого проверьте сообщения доставки/готовности. Команда в чате сохранена.
Сам неоком, его иконку и общий список рисует Launcher. При выгрузке удаляется
только собственная регистрация; остальные моды не затрагиваются.

Локально проверены контракт регистрации, готовность, смена owner, повторная
регистрация и очистка на API-адаптере. Отображение в Windows не проверено.

## Обновления из Launcher

Источник: публичные релизы https://github.com/klimesrenz/evejs-mods/releases .
Первую версию с блоком updates установить вручную через Add ZIP. Далее
использовать Check mod updates и кнопку Update после просмотра изменений.
Проверка не устанавливает обновление автоматически. Перед обновлением
остановить сервер и закрыть клиент. Совместимость исходников проверяется
helper мода; ограничения версии сервера сохраняются.

Идентификатор мода и пути данных сохранены. Склад Skyhook PI и конфиги
вне каталога пакета не входят в ZIP и не требуют preserveFiles. После
обновления проверить состояние производства, при необходимости включить
его снова. Подробный порядок релизов — в README репозитория.

## Проверка обновления через Launcher

В 0.1.4 номер версии отображается в заголовке окна: **Market Search 0.1.4**.
После обновления через Check mod updates → Update и перезапуска сервера/клиента
откройте окно из Mods и сверяйте этот номер. Это подтверждает получение
нового клиентского кода, а не только замену записи в списке Launcher.

Перед обновлением закройте клиент и остановите сервер. Для Skyhook PI
запишите остатки до обновления; после сверяйте их с учётом прошедших циклов,
выбранной паузы и ёмкости. Если helper поставил производство на паузу,
включите его снова. Параметры производства и формат склада в этом выпуске
не изменены. Для Market Search проверьте поиск известного товара.
