# Переработка PI 0.1.0

Отдельное окно Mods для производства P2–P4 из материалов личного ангара.
Можно использовать P1 со Skyhook PI или купленные материалы. Чертежи,
планетарные фабрики, ISK, навыки и промышленный сервисный модуль не требуются.

## Производство

1. Докнитесь на NPC-станции или в доступной цитадели. Положите материалы
   непосредственно в личный ангар, вне кораблей и контейнеров.
2. Mods → Переработка PI, либо чат `!piprocessing`.
3. Выберите продукт и число циклов, нажмите «Рассчитать» или «Максимум».
4. «Запустить» списывает всю партию сырья. Отмены задания нет.
5. Во вкладке «Задания» после таймера нажмите «Забрать» в том же месте.

Рецепты и длительность берутся из серверных данных PI. Все выбранные циклы
идут параллельно: 100 циклов занимают столько же времени, сколько один.
Игрового лимита линий/заданий нет. Технически одна партия ограничена
2147483647 единицами каждого входа/выхода и 10000 исходными стопками;
объедините стопки или разделите чрезмерно большую партию на задания.
Каждый следующий тир запускается отдельно. Автоповтора и частичной выдачи нет.

Таймер продолжает идти при закрытом клиенте, остановленном сервере и
отключённом моде. Готовые партии сохраняются без срока истечения.
Результат всегда привязан к исходному ангару. При потере доступа к структуре
нужно восстановить доступ; при её уничтожении/снятии результат остаётся в БД,
но получить его в другом месте нельзя. Автоматического Asset Safety нет.

Если ответ потерян, используйте «Повторить запрос»: сохранённый идентификатор
не позволит повторно списать сырьё/выдать результат. При смене места сначала
вернитесь в место исходного запроса. Не удаляйте pending-запрос вручную при
ошибке хранилища: сначала восстановите сервер и повторите запрос.

## Установка и проверка на Windows

Требуется Native EVE.js, Node.js 24+, Launcher 1.0.69+.
Manifest допускает названия сборок 0.12.9/0.12.19, но helper дополнительно
проверяет конкретные исходники. Неизвестный build отклоняется; guard не отключать.
Файл `lib/reviewed.json` содержит нормализованные SHA-256 изученных файлов.

1. Остановить игровой сервер, закрыть EVE-клиенты.
2. Launcher → Mods → Add ZIP → `PIProcessing-0.1.0.zip` → Enable.
3. Запустить сервер и клиент; открыть окно из общего меню Mods.
4. На первой проверке запустить 1 цикл доступного P2-рецепта. Сверить списание
   всех материалов. Перезапустить сервер до завершения, дождаться таймера,
   получить результат и сверить количество в ангаре.
5. Повторить в цитадели, проверить отказ получения на другой станции,
   смену персонажа и работу рядом с Skyhook PI/Market Search/AutoMining.

При `Unreviewed ...` нужны указанный файл и версия работающей сборки для
адаптации. `UI not ready` — проверить серверный лог, перезапустить клиент.
`STORE_BUSY` — другая копия сервера владеет БД; живой процесс не вытеснять.
Ошибки recovery требуют сохранения БД и логов для диагностики, а не удаления.

## Данные и обновления

Задания: `<EVE root>/_local/mods/pi-processing/state.sqlite` с WAL/SHM рядом.
Они не входят в ZIP и сохраняются при обновлении/удалении пакета. Перед
окончательным удалением мода заберите готовые партии. Для резервной копии
остановите сервер и копируйте каталог состояния целиком; не откатывайте
отдельно БД мода без согласованного состояния host inventory и его квитанций.

Пакет использует источник будущих обновлений `klimesrenz/evejs-mods`,
теги `pi-processing-v...`; первое подключение через Add ZIP. Доступность
обновления зависит от публикации соответствующего GitHub Release.

## Статус проверки

Локально проверены расчёты, SQLite rollback/reopen/lease, реальные функции
атомарного списания и квитанций на двух изученных исходниках, recovery заданий,
RPC, сохранение pending-запроса, helper и композиция доставки/преобразований.
Для host-функций использован временный адаптер хранения: это не запуск полного
Windows-сервера. Каталог реального Windows SDE и исполнение окна в клиентском
Python 2.7 требуют проверки пользователем. Синтаксическая проверка их не заменяет.
