# Skyhook PI 0.1.14

## Что изменилось

- Кнопка «Забрать» теперь собирает все накопленные P1 выбранного скайхука одним запросом.
- Выбор отдельного продукта и ручной ввод количества больше не нужны.
- Несколько типов P1 выдаются в корабль одной атомарной idempotent-операцией Core.
- Если весь склад не помещается, выбранный трюм заполняется по порядку товаров, а остаток сохраняется на скайхуке.
- Проверки корпорации, корабля, системы, дистанции и совместимости специального трюма сохранены.

## Совместимость

- EveJS Core `261018.1`.
- Native Launcher `1.0.74+`.
- Node.js 24+.
- Формат `_local/mods/skyhook-pi/state.sqlite` не изменён; незавершённые выдачи предыдущей версии восстанавливаются в прежнем формате.

## Проверка после обновления

1. Остановить сервер и полностью закрыть EVE-клиент.
2. Обновить мод и запустить сервер; проверить строку `[SkyhookPI] 0.1.14 loaded`.
3. Запустить новый клиент и открыть окно **Skyhook PI 0.1.14**.
4. Выбрать скайхук с несколькими накопленными P1, подлететь к нему и нажать «Забрать» без выбора продукта.
5. Проверить, что все помещающиеся продукты появились в выбранном трюме, а остатки на скайхуке уменьшились на те же количества.
6. Повторить с частично свободным трюмом и после перезапуска сервера.

Локально проверены сервисная batch-операция, расчёт заполнения трюма, совместимость с текущим Core, transforms и финальный ZIP. Полная игровая приёмка в Windows-клиенте ещё требуется.
