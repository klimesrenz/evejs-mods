# PI Processing 0.1.4

Исправлена доставка клиентского UI при одновременном включении нескольких модов.

- Максимальный размер составного сжатого login payload увеличен с 256 до 512 KiB, как в актуальном Market Search.
- PI Processing больше не пропускает регистрацию клиентского окна, когда предыдущие моды уже сформировали payload больше 256 KiB.
- Добавлен regression-тест композиции с существующим payload больше 256 KiB.

Совместимость не изменена: EveJS Core `261018.1`, Launcher `1.0.74` или новее.

Перед обновлением остановите сервер и закройте EVE-клиенты. После обновления запустите сервер и клиент заново; окно доступно в Neocom → Mods и командой `!piprocessing`.
