# Skyhook PI 0.1.11

Исправлен доступ к штатной таможне скайхука: сервер передаёт клиенту активность
структуры, а inventory broker распознаёт работающий скайхук как таможенный склад.
Это устраняет найденные причины неактивного Access Customs Office и отказа
Launchpad находить скайхук. Отдельный POCO не требуется.

Налоги, личное хранение товаров и штатный импорт/экспорт сохраняются. Склад P1
мода остаётся отдельным. Файлы сервера/клиента и существующие данные не меняются.
Добавлена проверка точного исходника inventory broker установленной сборки.

Перед установкой остановить сервер и закрыть клиент. После запуска проверить
импорт/экспорт небольшого количества PI через Launchpad и сохранность после
restart. До отката забрать товары из таможенного склада скайхука.

Локальная проверка состояний, клиентских условий и совместимости пройдена.
Игровая приёмка Windows ещё не выполнена.
