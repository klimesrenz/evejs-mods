Skyhook PI 0.1.8

Номер версии теперь виден в заголовке окна: Skyhook PI 0.1.8. Это позволяет подтвердить, что после обновления Launcher клиент получил новый код.

Обновление с 0.1.7 доступно через Check mod updates → Update. Перед установкой закрыть клиент и остановить сервер, затем запустить их заново. Окно открывается из Neocom → Mods или привычной чат-командой.

Идентификатор мода, источник обновлений, внешние настройки и данные сохранены. Игровая логика и формат PI-склада не менялись. Проверка установки через Update на Windows проводится на этом выпуске.
