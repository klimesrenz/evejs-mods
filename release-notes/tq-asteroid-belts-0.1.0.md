# TQ Asteroid Belts 0.1.0

Первый выпуск data-driven мода для стандартных астероидных поясов EveJS.

- Точный состав и количество астероидов для 40 928 TQ-поясов.
- 2 123 854 астероида и 249 314 пар belt/type из клиентской FSD-таблицы TQ.
- Штатная геометрия, stable item IDs, materialization и mining persistence EveJS.
- Native fallback для custom belts, отсутствующих в TQ manifest.
- Fail-closed совместимость с EveJS 0.12.9 / 261018.1.
- Явный конфликт с FourModeAsteroidBelts.
- Полная проверка pinned manifest и исходного клиентского ресурса.

Не заявляются точные TQ-координаты, визуальные радиусы и индивидуальный объём руды в каждом камне. Они остаются отдельными стадиями parity.
