# PI Processing 0.1.0

Первый пакет переработки P2–P4 через окно Mods на NPC-станциях и в доступных
цитаделях. Сырьё берётся из личного ангара, результат выдаётся там же.
Офлайн-таймер, параллельные циклы без игровых лимитов, без ISK и навыков.
Задания и защита от повторных запросов сохраняются между перезапусками.

Перед установкой остановить сервер и закрыть клиенты. Импортировать ZIP
через Mods → Add ZIP. Для первой приёмки использовать небольшую партию P2.
Windows-приёмка ещё не проведена. Изученные исходники проверяются helper;
неизвестная сборка требует адаптации, guard не отключать.

При уничтожении структуры автоматического Asset Safety для заданий нет.
Состояние вне ZIP: `_local/mods/pi-processing/state.sqlite`.
