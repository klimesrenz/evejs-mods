market-search 0.1.3

Добавлен канал обновлений klimesrenz/evejs-mods. Первый пакет с updates импортировать через Add ZIP; следующие версии будут доступны через Check mod updates.

Включены открытие из общего меню Mods и сжатие большого login payload. Skyhook PI включает двухпанельный список структур и продуктов с фильтрами.

Перед установкой остановить сервер и закрыть клиент. Сохранены id модов и внешние пути данных; PI-склад удалять не нужно. Пакеты предназначены для Native Launcher 1.0.69+; helper проверяет совместимость исходников EVE.js.

Локальные проверки пройдены; отображение меню, GitHub-обновление на Windows и полная игровая приёмка последних изменений ещё не подтверждены.
