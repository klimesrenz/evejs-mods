# PI Processing 0.1.1

Выбор конечного P2/P3/P4 и производство сразу из P1. Мод раскрывает цепочку
рецептов, суммирует потребность в P1 и рассчитывает максимум по личному ангару.
Промежуточные P2/P3 создавать не нужно.

Время включает всю цепочку с параллельным выполнением независимых ветвей.
Количество задаётся партиями; выход одной партии виден в списке продуктов.
Список материалов прокручивается, чтобы помещались длинные рецепты P4.

Пример по проверенному SDE: по 80 Oxygen, Biomass, Silicon и Industrial
Fibers → 3 Data Chips за 2 часа. Запущенные задания 0.1.0 сохраняются.

Перед обновлением остановить сервер и закрыть клиенты; после Update
перезапустить их. Для первой проверки рассчитать одну партию Data Chips.
Локально проверены все 53 рецепта P2–P4; Windows-приёмка 0.1.1 ещё предстоит.
