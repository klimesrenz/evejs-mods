# PI Processing 0.1.3

- Добавлена совместимость с EveJS Core `261018.1` (`dbcd89a79`).
- Session identity переведена на штатный Core resolver.
- Исправлено восстановление `starting`/`delivering`: достоверно отсутствующая
  inventory-квитанция больше не считается неопределённым чтением и не оставляет
  задание зависшим навсегда.
- Compatibility guard расширен на реально используемые RPC, delivery и chat
  host-файлы.

Формат `_local/mods/pi-processing/state.sqlite`, рецепты и длительность заданий
не изменены. Локальные контрактные проверки выполнены на Windows; игровая
приёмка в EVE-клиенте остаётся отдельным шагом перед публикацией.
